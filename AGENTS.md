## Living Docs

This project uses [`@GuardianBob/living-docs`](https://github.com/GuardianBob/living-docs) for narrative continuity and task memory.

- **Read first:** `.living_docs/INDEX.md`, then `.living_docs/status/current.md`
- **Per-task shards:** `.living_docs/memory/`, `.living_docs/adventures/chapters/`, `.living_docs/git-commits/`
- **Generated index:** `.living_docs/INDEX.md` — NEVER hand-edit (regenerated by `living-docs-rebuild`)
- **After completing a task:** write the four shards, then `npx living-docs-rebuild`
- **The `living-docs` skill auto-loads** with full workflow detail; hooks remind you to update shards
- **Setup (once per repo):** `npx living-docs-bootstrap`
- **Schema docs:** `.living_docs/README.md`
